Design, Modelling and Structural Analysis of a Go-Kart Chassis

Mini Project – Mechanical Engineering

This project focuses on the design, modelling, and structural analysis of a Go-Kart chassis. The chassis was designed using SolidWorks and structurally analyzed using ANSYS under different loading conditions.

Project Objectives

- Design a Go-Kart chassis frame using SolidWorks.
- Select a suitable material based on its mechanical properties.
- Analyze the chassis using ANSYS.
- Evaluate stress, deformation, and factor of safety.
- Study the structural behavior under front, rear, and side impact loading.
- Develop a strong, safe, and lightweight chassis structure.

Software Used

- SolidWorks – 3D CAD modelling
- ANSYS Workbench – Finite Element Analysis (FEA)

Material

The chassis frame uses AISI 1020 Mild Steel.

Property| Value
Yield Strength| ≈ 350 MPa
Ultimate Tensile Strength| ≈ 420 MPa
Density| 7850 kg/m³
Young's Modulus| 200 GPa

Chassis Tube Specifications

Component| Tube Size
Main chassis rails| 25.4 mm × 1.2 mm
Cross members| 22 mm × 1.2 mm
Support members| 19 mm × 1.2 mm

Structural Analysis

The chassis was analyzed under different loading conditions:

- Driver load
- Front impact
- Rear impact
- Side impact
- Braking load

The ANSYS analysis includes:

- Mesh generation
- Boundary conditions
- Load application
- Equivalent (von Mises) stress
- Total deformation
- Factor of safety
